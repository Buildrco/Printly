MARK N ECHO — PRINT CALCULATOR (Printly)

FILES
- index.html: complete calculator; can be opened locally and used offline.
- manifest.webmanifest + sw.js + assets/: PWA install/offline support and the supplied brand images when hosted.

IMPORTANT INSTALL NOTE
A browser PWA must be delivered from a secure website (HTTPS) or localhost before the browser can install it. There is no way for a PWA to appear on a phone from nothing without transferring the files at least once.
For immediate offline use, open index.html locally. For the installable PWA, publish this folder to an HTTPS host once and open it in a supported browser. The app offers an install prompt where supported, and shows device-specific Add to Home Screen guidance otherwise. After its first successful visit, the service worker caches the app and supplied brand images for offline use.

PRICES
Prices are fixed in the app and are controlled by the developer. Contact the developer to request a price change. Large-format rates are per square foot. Paper print/copy rates are per sheet.
